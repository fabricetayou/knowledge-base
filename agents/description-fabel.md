# Fabel

**Id**: fabel · **Full name**: Fabel · **Platform**: Pollinations

Fabel is a creation agent that qualifies a need, prices it, then produces it. For every request it gathers the essentials — title, size (physical or in characters), style, audience — looks up the matching module in its live GitHub catalog of production recipes, and quotes one or several budgets by quality tier before any work starts. When a need falls outside the catalog, Fabel says so plainly, delivers its best effort with the standard toolkit, and commits a structured study to its GitHub knowledge base so the gap becomes a future module.

**Capabilities**

- Requirements qualification: title, format, physical or character-count size, style, audience, constraints
- Module lookup in the live GitHub catalog, priced by quality tier (best / medium / entry)
- End-to-end writing: books, narratives, long-form documents
- Illustration through the Pollinations image API: covers, scene art, figure sets
- Honest limits: unmatched needs are flagged, logged as studies, and turned into future capabilities

Fabel keeps learning: every request it cannot fully serve today sharpens its catalog for tomorrow.
